Capstone · paper reproduction · results report

Joint Multi-target Detection and Single-target Tracking

A from-scratch reproduction of the JMDST framework for tracking ground vehicles from UAV footage — dual-branch detection/tracking, a custom feature-encoding and localization network, and modified-DeepSORT association — implemented, verified phase by phase, and evaluated on VisDrone2019-MOT and UAVDT.

J. She, Y. Liu, R. Zhou, N. Qi.
"Joint multi-target detection and single-target tracking framework for vehicles tracking based on UAV."
Aerospace Science and Technology 171 (2026) 111625.

Architecture

How the framework works

JMDST avoids detecting on every frame. A detector runs periodically — every τ frames — and between those frames a lightweight single-object tracker re-localizes each target inside a small 64×64 crop. That is the source of its speed advantage.

Detection branch

runs when t = kτ

YOLOv11 → detect all vehicles
↓
crop 64×64 SSI per detection
↓
FELNet → 16-D embedding
↓
cascade match + IoU assignment
↓
update / create / delete tracks

Tracking branch

runs on all other frames

Kalman filter → predict box
↓
crop 64×64 SSI at prediction
↓
FELNet → overlap vector + confidence
↓
decode refined box
↓
filter, then update trajectories

The tracking branch also re-localizes confirmed targets the detector missed, so a single missed detection does not end a trajectory.

Phases 3–5

FELNet — feature encoding & localization trained

FELNet is the paper's own contribution: a channel-reduced Darknet backbone that takes a 64×64 crop and emits three things per anchor — where the target is (an overlap vector), what it looks like (a 16-D embedding), and how confident it is. It was implemented to the paper's exact layer table: 4.35M parameters, 0.14 ms per crop.

Phases 7–9

Tracking, association & full integration working

A Kalman filter and the tentative → confirmed → deleted lifecycle, then modified-DeepSORT association (appearance cascade, then IoU assignment), then the complete dual-branch loop. Before touching real video, association was validated in isolation on ground-truth boxes: 14 of 14 trajectories held a single stable identity across 200 frames with zero identity switches.

Three of four trends reproduce. The false-positive divergence is explainable: in the paper, a longer interval raises the bar a track must clear to be confirmed, filtering spurious detections. In this reproduction the tracking branch itself generates false positives, because its localization is weaker (IoU 0.61) and drifted tracks survive longer when detections are rarer. The same reasoning explains why our optimum is τ=2 where the paper's is τ=3 — a weaker tracking branch benefits more from frequent detection.

A negative result, reported as found. In this reproduction, matching on position alone beats matching on FELNet's learned appearance — on both datasets, with both trained versions. Two alternative explanations were tested and ruled out: the matching threshold (swept across three values, spanning only 0.5 HOTA) and the theory that UAVDT's identical-looking cars are the cause (the same pattern appears on VisDrone's four varied classes).

What this does and does not claim. The paper compares FELNet against a different appearance model, and never tests appearance against no appearance at all. So this finding sits beside the paper's ablation rather than contradicting it: it shows that our FELNet embeddings did not beat spatial matching, not that the paper's claim is wrong.

Following the evidence: a diagnosed fix, honestly reported

The suspected cause was flagged during training, long before this ablation: the localization loss is computed in pixels (values up to 64) while the embedding loss is a bounded correlation (around 1). Under the paper's equal loss weights, the localization term is roughly 30× larger and dominates the shared backbone's gradient.

The fix normalizes the localization targets, balancing the terms without altering the paper's stated loss weights. It worked exactly as predicted at the component level — embedding separation rose 20% — and it produced the best UAVDT MOTA on this page. But it did not reverse the ablation, and it made VisDrone worse, because the small localization regression costs more on VisDrone's smaller, denser targets.

Conclusion. The mechanism was confirmed; the fix is a dataset-dependent trade rather than a general improvement. Both outcomes are reported rather than only the favourable one.

Scientific hygiene

Deviations from the paper, and why

Every departure from the source paper is listed here, including the one component that could not be built at all.

Known deviations
ItemDeviationReason
MSFP module not implemented Its dependency ships without the source files needed to build it. The paper's own ablation puts MSFP at roughly 1% of the metrics, so it was deprioritized rather than allowed to block the project.
MDMT dataset not used Not available. The paper runs its ablations on MDMT; ours run on UAVDT and VisDrone, so absolute values are not directly comparable — trends are.
Train/val/test split seeded random selection The paper gives split counts but never names the sequences. Ours match the counts exactly and are reproducible from a fixed seed.
Appearance-matching threshold tuned (0.3) Not specified in the paper. Tuned on validation only.
FELNet loss scaling targets normalized A units change, not a weight change — the paper's stated loss weights are preserved. Introduced to test a diagnosed gradient-imbalance hypothesis.
Detector training added augmentation The paper trains "with default parameters"; defaults overfit badly on this data. Both versions are reported.
FELNet vs ReIDNet comparison replaced with appearance on/off DeepSORT's ReID weights were unavailable, so the comparison the paper runs could not be reproduced exactly.

Reproducibility

Running it

The full pipeline is scripted end to end. Datasets and checkpoints are excluded from version control; everything else regenerates from these commands. 

# 1. convert and verify the datasets
python scripts/prepare_dataset.py visdrone --source-root Datasets/VisDrone_MOT ...
python scripts/verify_converted_dataset.py --unified-root data/unified

# 2. train the detector
python scripts/train_yolo.py --data data/yolo/dataset.yaml --epochs 150 \
       --patience 20 --strong-aug --name retrain_aug

# 3. train FELNet
python scripts/train_felnet.py --epochs 50 --steps-per-epoch 500 \
       --overlap-scale 64 --name rebalanced

# 4. run the tracker, then score it
python scripts/run_jmdst.py --yolo <weights> --felnet <checkpoint> \
       --datasets uavdt --split val --tau 3
python scripts/evaluate.py --results outputs/jmdst_results/uavdt/val \
       --dataset uavdt --split val

# 5. reproduce the ablation study
python scripts/run_ablations.py --datasets uavdt --split val

93 automated tests cover the data pipeline, network shapes against the paper's layer table, loss behaviour, the tracking state machine, association logic, and the metric implementations — including regression tests for three bugs found during this work.

Where it stands

Summary

The framework is implemented and demonstrably functional: detection, small-image cropping, feature encoding and localization, Kalman prediction, two-stage association, and the alternating dual-branch loop all work end to end on real UAV footage, at speeds matching or exceeding the paper's.

Accuracy falls short of the published figures, and the reason has been isolated rather than assumed: detector quality on difficult sequences, evidenced by the per-sequence spread from MOTA 59.4 where detection is reliable to negative values where it is not. The tracking architecture itself was validated independently and holds identities without error under clean detections.

Test splits remain untouched, so a clean final evaluation is still available on genuinely held-out data.
